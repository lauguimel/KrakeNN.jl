Generalised Newtonian natural convection ​

Natural convection of a generalised Newtonian fluid (viscosity depending on the local shear rate) in a differentially heated square cavity: hot west wall, cold east wall, adiabatic top and bottom, no-slip walls. Driver run_natural_convection_gnf_2d, which couples the thermal double-distribution D2Q9 solver of the Newtonian cavity to the shear-rate-dependent collision of the rheology chapter of the theory section (rheology theory page).

Status: CPU-validated, N ≤ 96; GPU run at N = 64, 128 and 256. The Newtonian limit, one De Vahl Davis point and two power-law points of Turan et al. (2011) are checked by the unit test. Eight power-law cases of that paper were run on CPU at N = 32 to 96, and the six Pr = 10 cases on one A100 at N = 64, 128 and 256 (see the GPU comparison). One of the six, Ra = 10⁴ with n = 1.8, is not converged.

Definitions ​

Ra and Pr are defined with the reference kinematic viscosity ν0 (nu0), not with a reference shear rate:

Pr=ν0α,Ra=βgΔTH3ν0α

In the code (gnf_reference_scales) this gives alpha = nu0/Pr and beta_g = Ra*nu0*alpha/(ΔT*H^3). The local viscosity of the fluid changes the flow but not these definitions.

The helper cavity_powerlaw(n; nu0, alpha, H) builds a power-law fluid ν=Kγ˙n−1, with γ˙=2SijSij, and

K=ν0(αH2)1−n,

so that the viscosity equals ν0 at the shear rate α/H2.

Correspondence with Turan et al. (2011) ​

Turan, Sachdeva, Chakraborty and Poole (2011) define a nominal viscosity from the characteristic shear rate α/L2 (their Eq. 5), νnom=(K/ρ)(α/L2)n−1, and use it in Ra and Pr (their Eq. 6):

Pr=Kραn−2L2−2n,Ra=gβΔTL2n+1αn(K/ρ).

With cavity_powerlaw, ν0 is exactly their νnom: inserting ν0=K(α/H2)n−1 in the two definitions above gives these expressions with L=H. Their shear-rate invariant eklekl/2 (with eij=2Sij) is the one used by Kraken.

nu0 has no counterpart in the paper: once Ra, Pr and n are fixed, it only sets the lattice time step. Two runs with different nu0 must give the same Nu; measured on CPU at N = 64, Ra = 10³, n = 0.6: Nu = 1.9931 (nu0 = 0.3) and 1.9914 (nu0 = 0.1), a 0.08 % difference. This holds only while the relaxation time stays moderate: at Ra = 10⁴, n = 1.4, nu0 = 0.3 lets the viscosity near the walls reach 1.69 (relaxation time 5.6) and gives Nu = 1.431, against 1.368 with nu0 = 0.1 (see the comparison below).

What differs from the paper, apart from the method (they solve the steady equations with a finite-volume code on a 100 × 100 non-uniform mesh):

  • the mirror image (hot wall on the other side), which leaves the mean Nu unchanged;

  • the buoyancy reference temperature: Kraken uses (Thot+Tcold)/2, the paper TC. The difference is a uniform body force, balanced by pressure;

  • PowerLaw clips the viscosity to [nu_min, nu_max], the paper does not. The result reports clamped_fraction; it was 0 in the CPU runs below, but not in every GPU run: in benchmarks/validation/natconv_gnf/results/turan_comparison.csv it is 6e-5 at Ra = 10³, n = 0.6, N = 256, 1.2e-4 to 9.8e-4 at Ra = 10³, n = 1.8, and 0.17 % to 8 % at Ra = 10⁴, n = 1.8 (N = 64 to 256, runs that did not converge);

  • the fixed-temperature walls are half-way anti-bounce-back walls, half a lattice spacing outside the first and last nodes, at the same place as the no-slip walls; Ra, Pr and Nu use the cavity width H=N, and Nu is the mean of a second-order one-sided wall gradient. These are the walls and the Nu formula of the Newtonian driver;

  • the paper's power-law data are for Pr ≥ 10; Pr = 0.71 is used here only for the Newtonian benchmark.

Run it on CPU ​

This runs in about two seconds per index on a laptop CPU (N = 32, Ra = 10⁴, Pr = 0.71):

julia
using Kraken

Pr, nu0, N = 0.71, 0.05, 32
scales = gnf_reference_scales(; Ra=1e4, Pr, nu0, H=Float64(N), T_hot=1.0, T_cold=0.0)

for n in (0.8, 1.0, 1.2)
    model = cavity_powerlaw(n; nu0, alpha=scales.alpha, H=N)
    r = run_natural_convection_gnf_2d(; N, Ra=1e4, Pr, nu0, rheology=model,
        max_steps=8000, check_every=1000, convergence_rtol=1e-5, min_steps=5000)
    println("n=$n Nu=$(round(r.Nu, digits=3)) steps=$(r.steps) ",
            "converged=$(r.converged) clamped=$(r.clamped_fraction)")
end

Pr = 0.71 lies outside the power-law data of Turan et al. (2011), so these values have no published counterpart. For a case of the paper, use Pr = 10 or more:

julia
Pr, nu0, N = 10.0, 0.3, 48
model = cavity_powerlaw(0.6; nu0, alpha=nu0/Pr, H=N, nu_min=1e-3, nu_max=2.0)
r = run_natural_convection_gnf_2d(; N, Ra=1e3, Pr, nu0, rheology=model,
    max_steps=60000, check_every=1000, convergence_rtol=1e-5, min_steps=5000)
r.Nu   # 1.993 measured; the paper gives 2.07 ± 0.07 (Fig. 9a), see below

The result is a NamedTuple with Nu, Temp, ux, uy, rho, the viscosity field nu_field, clamped_fraction (share of nodes sitting at a viscosity cutoff at the last step), steps, converged and Nu_drift.

The extrapolated row assumes an error in 1/N²: at fixed nu0 the grid error and the compressibility error of the lattice both scale that way. The measured ratio of successive differences (N = 32, 48, 64) is 2.90, against 2.86 for an exact 1/N² error. The pairs (32, 48) and (48, 64) extrapolate to 5.393 and 5.392.

Reading of the table:

  • At Ra = 10⁴, for n = 0.6 to 1.4 (n = 1.4 with nu0 = 0.1), Kraken agrees with the paper within 0.7 % on a 64² grid, and within 0.2 % after extrapolation for n = 0.6. The same mapping of Ra and Pr is used at every point, so this rules out a mismatch of definitions between Kraken and the paper.

  • At Ra = 10³, n = 0.6, Kraken is 3.7 % below the paper value, just outside its reading uncertainty. This gap is not a grid error: Nu changes by 0.05 % from N = 48 to N = 96 and by 0.08 % when nu0 is divided by 3. Its origin is not measured. What is known: Fig. 9a has a 0 to 40 axis, so its reading is coarse; the same figure gives 5.44 at Ra = 10⁴ where Fig. 10 gives 5.40; and for n = 1 it gives 1.14, 2 % above the Newtonian value of Kraken at Pr = 10 (1.120), whereas changing Pr from 0.71 to 10 moves Kraken's Nu by only 0.14 % and De Vahl Davis gives 1.117 at Pr = 0.71. The gap is therefore likely a reading or plotting offset of Fig. 9 at Ra = 10³ (inferred, not proved). A real difference between the two solutions at Ra = 10³ cannot be excluded without tabulated values.

  • For a shear-thickening fluid the viscosity is largest at the walls, where the shear is largest, and the BGK wall error grows with the relaxation time. With nu0 = 0.3, n = 1.4 reaches a wall viscosity of 1.69 and Nu is 5.2 % high; with nu0 = 0.1 the viscosity stays below 0.58 and the gap falls to 0.6 %. For n = 1.8, nu0 = 0.3 and 0.1 put 84 % and 22 % of the nodes at the nu_max cutoff at Ra = 10⁴ and give no usable result. With nu0 = 0.05, Ra = 10³ converges 0.1 % below the paper (0.1 % of the nodes at nu_min), while Ra = 10⁴ is still drifting after 1.5 million steps (1.8 diffusion times, last relative change 1.8e-5 per 1000 steps), with 0.1 % of the nodes at nu_max, and stands 1.1 % below the paper.

Reading of the table:

  • The n=1 row shows that the new driver and the Newtonian driver solve the same discrete problem; it does not validate the non-Newtonian physics.

  • The De Vahl Davis row is a 0.05 % agreement on a 64² mesh at Ra = 10³; at Ra = 10⁴ the same comparison (not in the test) gives 2.2535 against 2.238, +0.7 %.

  • The trend row says that shear-thinning raises the heat transfer and shear-thickening lowers it, as expected physically; Pr = 0.71 has no published power-law counterpart.

  • The two Turan rows split the comparison on purpose. At Ra = 10⁴ the figure is read to 0.4 % and Kraken agrees with it, so the test gates Kraken against the paper with a 1 % gate set by the paper's precision. At Ra = 10³ a gate against 2.07 would have to be at least 4 %, which would mostly test the reading of a figure and would let a 3 % change of Kraken's solution pass unseen; the test therefore freezes Kraken's own converged value, so that any change of the discrete solution fails, and the 3.7 % gap stays documented.

Not yet verified ​

  • GPU coverage. The six cases were run on one A100 only. Ra = 10⁴ with n = 1.8 did not converge at any N, so it has no validated value. The older qualitative sweep at Pr = 0.71 (run_natconv_gnf.jl) is not run.

  • The Ra = 10³ gap of −3.7 % for n = 0.6 is explained by inference only.

  • Shear-thickening fluids need a small nu0; n = 1.8 at Ra = 10⁴ did not reach a steady state on CPU (N = 64) or on GPU (N = 64 to 256).

  • Ra = 10⁵ and 10⁶ are not compared, nor Table 2 of the paper (Ra = 10⁶, Pr = 100, the only tabulated Nu values), which needs a thermal relaxation time within 0.01 of 1/2 and about 10⁷ steps at N = 512.

  • Pr dependence is not checked: all power-law comparisons use Pr = 10.

  • Float32 was not tested.
