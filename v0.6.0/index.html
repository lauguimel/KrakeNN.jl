Kraken.jlGPU-native, method-agnostic multiphysics in Julia

A method-agnostic PDE framework whose mature core method is Lattice Boltzmann. Write a reproducible .krk case or a direct Julia driver, then run it on CUDA, Metal, or CPU backends.

Quick start ​

julia
using Kraken

# Lid-driven cavity at Re = 100 on a 128×128 grid
N = 128
ν = 0.1 * N / 100  # ν = u_lid · N / Re
config = LBMConfig(D2Q9(); Nx=N, Ny=N, ν=ν, u_lid=0.1, max_steps=30000)
result = run_cavity_2d(config)

The same simulation can be written declaratively in a .krk file and launched from a shell:

# cavity.krk — lid-driven cavity at Re = 100
Simulation cavity D2Q9
Domain     L = 1.0 x 1.0   N = 128 x 128
Physics    nu = 0.128
Boundary   north velocity(ux = 0.1, uy = 0)
Boundary   south wall
Boundary   east  wall
Boundary   west  wall
Run        30000 steps
bash
krk cavity.krk

Citing Kraken ​

If you use Kraken.jl in your research, please cite it. The repository ships a CITATION.cff, so GitHub's "Cite this repository" button (top-right of the repository) gives a ready-made entry.

bibtex
@software{kraken_jl,
  author  = {Maitrejean, Guillaume and Zhao, Jiachen and Sauret, Emilie},
  title   = {{Kraken.jl}},
  year    = {2026},
  version = {0.6.0},
  doi     = {10.5281/zenodo.22747126},
  url     = {https://github.com/lauguimel/Kraken.jl}
}

Each release is archived on Zenodo under two DOIs. Use 10.5281/zenodo.22747126 — the one above — to cite the software in general: it always resolves to the most recent archived release. Use the version-specific DOI instead when the exact code matters for reproducibility; for v0.5.1 that is 10.5281/zenodo.23598327, and each Zenodo record lists its own.
